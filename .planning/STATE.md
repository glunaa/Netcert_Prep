## Project Summary
React + TypeScript + Tailwind CSS v4 exam prep app for CompTIA Network+ (N10-009) and AWS Cloud Practitioner (CLF-C02). Deployed on GitHub Pages at glunaa/Netcert_Prep.

## What's Built
- Net+ study guide: 11 tabs (OSI, TCP/IP, Ports, Subnets, IPv6, Wireless, Routing & Switching, Security, Troubleshooting, Network Types, Quick Facts)
- AWS CLF-C02 study guide: 6 tabs (Services, Cloud Concepts, Security & IAM, Well-Architected, Billing & Pricing, Infrastructure)
- Practice test engine for both exams (30 questions each)
- VLSM subnet calculator
- CLI reference page
- VPC reference page
